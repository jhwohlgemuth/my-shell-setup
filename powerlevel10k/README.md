# Powerlevel10k

This package installs the Powerlevel10k configuration at `~/.p10k.zsh`.

## Install

```shell
stow --dir "${HOME}/.dotfiles" --target "${HOME}" --stow powerlevel10k
```

Install Powerlevel10k and source its theme from Zsh before loading this configuration. Run `p10k configure` when you want to regenerate it interactively.
